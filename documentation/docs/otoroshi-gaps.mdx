# Known limitations of the data plane

A gap in the data plane is fixed in the data plane — in Otoroshi or one of its extensions — never
worked around in the product: a workaround there would freeze the product's model for nothing.
Meanwhile, the product says what really applies rather than promising what the gateway cannot hold.

This page lists what still limits the product: the gaps **open**, reported upstream, with what the
product does meanwhile. The gaps already fixed are not here: the product requires Otoroshi 18.1,
which holds their fixes. The full history — every gap found, its source references, its fix — is
kept in
[`OTOROSHI-GAPS.md`](https://github.com/cloud-apim/otoroshi-api-management/blob/main/OTOROSHI-GAPS.md).

| # | Gap | Severity | Status | What the product does |
|---|---|---|---|---|
| G-23 | A key cannot serve several subscriptions: a key is its subscription's own, one api, one plan ([#2963](https://github.com/MAIF/otoroshi/issues/2963)) | medium | ⬜ open | one key per subscription; a credential for several subscriptions waits for it |
| G-24 | Threat Protection Suite: the global table of Threat Studio does not see the plan plugins: a second firewall runs on a plan already protected, the scores add up and the policy of the table decides ([waf#60](https://github.com/cloud-apim/otoroshi-waf-extension/issues/60)) | high | ⬜ open | keep the global table off the apis protected per plan |
| G-26 | Threat Protection Suite: a security event names the api, not the plan ([waf#61](https://github.com/cloud-apim/otoroshi-waf-extension/issues/61)) | low | ⬜ open | the plan from the key that called; the api only otherwise |
| G-27 | Threat Protection Suite: with the core rule set, every call scores a firewall match — its initialization rules count as matches ([waf#62](https://github.com/cloud-apim/otoroshi-waf-extension/issues/62)) | medium | ⬜ open | a policy that refuses at 90 |
| G-28 | Threat Protection Suite: a firewall that blocks on its own sends no security event, only its trail ([waf#63](https://github.com/cloud-apim/otoroshi-waf-extension/issues/63)) | medium | ⬜ open | the firewall reports, the threat response decides |
